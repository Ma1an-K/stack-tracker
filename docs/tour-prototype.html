Draft for review

Feature tour after first sign-in

A short swipe-through sheet that shows each new account the four things the app does. It opens once, the first time someone reaches Home, and can be replayed from the menu. Pick a user type to see their version, then swipe or tap Next on the phone.

Who is signing in

When it shows

  • Once, on the first visit to Home after host setup, joining, or choosing "Just settle tonight".
  • Before the install sheet. The "Keep it one tap away" sheet waits until the tour is closed, so two sheets never stack.
  • Skip closes it for good, same as finishing it. Remembered on the account, so it doesn't come back on another device.
  • Replay any time from the header menu: "Take the tour".
  • New accounts only. Existing users are marked as having seen it, the same way the tips were.
